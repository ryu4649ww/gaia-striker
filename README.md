# GAIA STRIKER ―地球奪還十二戦線―

宇宙機械生命体に侵略された地球の名所12か所を取り戻す、縦スクロールシューティング（ブラウザーで遊べます。PC・スマホ縦横対応）。

**遊ぶ：https://ryu4649ww.github.io/gaia-striker/** （v2.0）

- 12面：東京・万里の長城・シンガポール・ギザ・ピサ・パリ・ロンドン・ニューヨーク・ナスカ・シドニー・イースター島・富士山。面ごとに固有の敵・中ボス・高速スクロール区間、名所が機械に作り替えられたボス（3形態）
- 兵器3種（赤 桜ショット／黄 火炎放射／青 リップル）×レベル3、レベル3でシールド
- 2秒ごとに色が変わるアイテム、レベル3で同じ色を取ると画面の敵と弾を一掃
- 追尾ミサイル、スピード4段階、難易度4段階（イージー／普通／難しい／鬼）
- キャラバンモード（2分・5分のスコアアタック）、タイトルのデモプレイ
- 絵は立体で作って描画（Blender）、曲はメタル18曲（録音された楽器の音をアンプに通して作曲）

操作：PC 矢印/WASD 移動・Z/スペース ショット・X スピード・Esc 一時停止／スマホ なぞって移動（自動連射）。

最初の版（v1.0）は https://ryu4649ww.github.io/gaia-striker/v1/ に残しています。素材の出典は THIRD_PARTY_LICENSES.txt。
